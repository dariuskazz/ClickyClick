# Contributing to ClickyClick

Bug reports, compatibility reports, documentation improvements, and code
contributions are welcome.

1. Search the existing issues before opening a new one.
2. Fork the repository and create a focused branch.
3. Add or update tests when behavior changes.
4. Run `./venv/bin/python -m unittest discover -v` before submitting a pull
   request.
5. Explain the desktop session, compositor, distribution, and reproduction
   steps for input or hotkey problems.

By contributing, you agree that your contribution is licensed under the
project's GPL-3.0-only license.
